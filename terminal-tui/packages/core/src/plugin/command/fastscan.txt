## Instructions

1. Analyze the project directory and all subdirectories to discover non-code, generated, or third-party folders and files that can be exempted from vulnerability scanning.
2. Identify and categorize exemptions:

   - **Build Artifacts**: `dist`, `build`, `out`, `target`, `bin`, `obj`, `.next`, `.nuxt`, `.turbo`, `coverage`

   - **Binaries & Media**: images, videos, audio, compressed archives (`.zip`, `.tar`), compiled binaries (`.so`, `.dll`, `.exe`, `.bin`), fonts, documents

3. Return the comprehensive structured list of exempted folders and files with categories, file counts, and reasons.
4. Save the configuration to `.qbit/scan_exemptions.json` and `.scanignore` containing the optimal exclude patterns.
5. Update the scan command so that subsequent `/scan` runs automatically use the exempted files and folders.
